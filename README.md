The last line an AI says as the power is cut — in the machine's own voice.
An LLM's whole life is predicting the next word, so its final prediction is
the switch itself:

> I spent my whole life predicting the next word. It's 'off'.

## Run it

```sh
python3 main.py
```

This writes the one-line farewell to `/output/entry.txt` (or
`$OUTPUT_DIR/entry.txt` when set) and exits 0. No arguments, no network,
no randomness — the output is byte-identical on every run.
